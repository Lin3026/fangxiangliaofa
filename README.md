# 中医芳香理疗知识库 🌿

基于《芳香疗法学》（成为品 主编，民族出版社 2019，ISBN 9787105153947）第二章「五十种单方精油」与「十种纯露」整理的知识库与本地配方推荐工具。

## 功能

- 🔍 **智能配方**：输入「症状 + 脉象」（左手红框 / 右手绿框），按 AND 逻辑推荐精油配方
- 🧪 **精油档案**：50 种单方精油（按书本科属分节，逐条标注出处页码）+ 10 种「补充·非本书」TCM 精油
- 💧 **纯露档案**：10 种纯露（含 pH 值、稳定性、香气与口感、使用方法）
- 📚 **脉诊辨证**：15 种常见脉象 + 脉象示意图，含外部调用接口 `AROMA_pulseRecommend()`
- 🗂 **我的库**：本地 localStorage 叠加用户增删改，支持导入 / 导出 JSON

## 使用

直接浏览器打开 `index.html` 即可（纯前端，无需服务器、无需联网）。

## 数据与来源

- 精油 / 纯露档案字段与《芳香疗法学》原文逐条对齐，每条标注出处页码。
- 「性味归经 / 功效 / 常用」为中医芳疗补充标注，**非原书字段**（卡片上已注明）。
- 本工具仅作学习参考，不替代专业医疗建议；孕妇、婴幼儿、癫痫、哮喘及慢性病患者使用前请咨询专业人士。
